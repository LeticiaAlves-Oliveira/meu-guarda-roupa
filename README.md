# Meu Guarda-Roupa 👗

App web pra registrar e consultar as roupas que você veste no dia a dia.

## Funcionalidades

- 📅 **Calendário interativo** — veja o look de cada dia
- 📝 **Registro por período** — manhã, tarde e noite
- 🏷️ **Categorias** — Trabalho, Beach Tennis, Correr, Lazer, Noite
- 🔍 **Pesquisa** — encontre quando usou uma peça específica
- 📊 **Estatísticas** — peças mais usadas, frequência por ocasião

## Como usar

### Pelo Telegram
Mande mensagem, áudio ou foto que eu registro pra você!

### Pelo site
Acesse `https://meu-guarda-roupa.onrender.com` e registre manualmente.
